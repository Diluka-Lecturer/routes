# Flutter Navigation Lab

Welcome to the Flutter Navigation practice lab! In this exercise, you will learn how to set up named routes and navigate between different screens in a Flutter application.

## 🚀 Getting Started

1. Clone this repository to your local machine.
2. Run `flutter pub get` to ensure all dependencies are fetched.
3. Open the project in your preferred IDE (VS Code, Android Studio, etc.).

## 📝 Your Tasks

Search for the `TODO` comments in the `lib` folder and complete the missing code to make the app functional.

*   **TODO 1 (`lib/main.dart`):** Define the route map for `/`, `/second`, and `/third`.
*   **TODO 2 (`lib/main.dart`):** Add the navigation code to push the `/second` route when the button is pressed.
*   **TODO 3 (`lib/second_page.dart`):** Add the navigation code to push the `/third` route.
*   **TODO 4 (`lib/second_page.dart`):** Add the navigation code to pop the current screen and return to the Home page.
*   **TODO 5 (`lib/third_page.dart`):** Add the navigation code to pop the current screen and return to the Second page.

## ✅ Expected Output
When completed, you should have a fully working application where you can navigate forward from Home -> Second Page -> Third Page, and backward using the provided buttons.
